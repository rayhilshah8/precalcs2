Precalc Semester 2 — Flashcards

All-original problems, same question types as your review sheet.

Trig Graphing — y = A·trig(Bx − C) + D

Amplitude = |A| (negative A flips the graph)
Period = 2π/|B| for sin, cos, sec, csc
Period = π/|B| for tan, cot
Phase shift = C/B (factor out B first to read it off)
Vertical shift = D (midline at y = D)
Range = [D − |A|, D + |A|] for sin and cos

Asymptotes

tan: Bx − C = π/2 + nπ
cot: Bx − C = nπ
sec/csc: wherever cos/sin = 0 (same as their base function)

Pythagorean Identities

sin²x + cos²x = 1
tan²x + 1 = sec²x
1 + cot²x = csc²x

Rearrangements (use these for substitution)

sin²x = 1 − cos²x
cos²x = 1 − sin²x
tan²x = sec²x − 1
cot²x = csc²x − 1

Reciprocal & Quotient Identities

csc x = 1/sin x    sec x = 1/cos x    cot x = 1/tan x
tan x = sin x / cos x
cot x = cos x / sin x

Even / Odd Identities

Odd (negate the output when you negate the input)

sin(−x) = −sin x    tan(−x) = −tan x    csc(−x) = −csc x    cot(−x) = −cot x

Even (output unchanged)

cos(−x) = cos x    sec(−x) = sec x

Cofunction Identities

sin(π/2 − x) = cos x     cos(π/2 − x) = sin x
tan(π/2 − x) = cot x     cot(π/2 − x) = tan x
sec(π/2 − x) = csc x     csc(π/2 − x) = sec x

Sum & Difference Formulas

sin(A ± B) = sin A cos B ± cos A sin B
cos(A ± B) = cos A cos B ∓ sin A sin B (signs flip!)
tan(A ± B) = (tan A ± tan B) / (1 ∓ tan A tan B)

Double Angle Formulas

sin 2x = 2 sin x cos x
tan 2x = 2 tan x / (1 − tan²x)

cos 2x — three versions, all equivalent

cos 2x = cos²x − sin²x
cos 2x = 1 − 2 sin²x (use when you want to eliminate cos)
cos 2x = 2 cos²x − 1 (use when you want to eliminate sin)

Power-Reducing Identities

sin²x = (1 − cos 2x) / 2
cos²x = (1 + cos 2x) / 2
tan²x = (1 − cos 2x) / (1 + cos 2x)

Half-Angle Formulas

sin(θ/2) = ±√((1 − cos θ) / 2)
cos(θ/2) = ±√((1 + cos θ) / 2)
tan(θ/2) = ±√((1 − cos θ) / (1 + cos θ))
tan(θ/2) = sin θ / (1 + cos θ) (no ± needed)
tan(θ/2) = (1 − cos θ) / sin θ (no ± needed)
Sign for sin/cos/first tan form: determined by which quadrant θ/2 falls in.

Conics — Parabola

Vertical (up/down): (x − h)² = 4p(y − k)
Horizontal (left/right): (y − k)² = 4p(x − h)

Key parts

Vertex: (h, k)
p = distance from vertex to focus = distance from vertex to directrix
Focus: (h, k+p) vertical  |  (h+p, k) horizontal
Directrix: y = k−p vertical  |  x = h−p horizontal
p > 0 → opens up/right    p < 0 → opens down/left
Latus rectum length = |4p|
To convert general form: complete the square on whichever variable is squared.

Conics — Ellipse

(x−h)²/a² + (y−k)²/b² = 1

Key parts

Center: (h, k)
a = semi-major axis (always under the larger denominator)
b = semi-minor axis
c² = a² − b²    (c < a always)
Foci: c units from center along the major axis
a² under x → horizontal major axis; a² under y → vertical
Vertices (major): (h±a, k) or (h, k±a)
Co-vertices (minor): the other direction, ±b from center
Eccentricity: e = c/a, where 0 < e < 1

Conics — Hyperbola

Horizontal: (x−h)²/a² − (y−k)²/b² = 1 (opens left/right)
Vertical: (y−k)²/a² − (x−h)²/b² = 1 (opens up/down)

Key parts

Center: (h, k)
c² = a² + b²    (c > a always)
Vertices: a units from center along the transverse axis
Foci: c units from center along the transverse axis
Asymptotes (horizontal): y − k = ±(b/a)(x − h)
Asymptotes (vertical): y − k = ±(a/b)(x − h)
Eccentricity: e = c/a, where e > 1

Radian ↔ Degree Conversion

Degrees → Radians: multiply by π/180
Radians → Degrees: multiply by 180/π
Complement: two angles summing to 90° (π/2) — only exists if angle < 90°
Supplement: two angles summing to 180° (π) — only exists if angle < 180°

Quadrant signs — ASTC

QI: All positive
QII: Sin (and csc) positive
QIII: Tan (and cot) positive
QIV: Cos (and sec) positive

Terminal points (x, y) on unit circle

r = √(x²+y²)    sin = y/r    cos = x/r    tan = y/x

Inverse Trig — Domains & Ranges

Composition trick

For sin(arctan(x/3)): let θ = arctan(x/3), so tan θ = x/3. Draw the right triangle with opposite = x, adjacent = 3, hypotenuse = √(x²+9). Then read off sin θ = x/√(x²+9) from the triangle.

Vectors

Component form from magnitude & angle: ⟨|v|cos θ, |v|sin θ⟩
Magnitude: |v| = √(v₁² + v₂²)
Unit vector: û = v / |v|
Dot product: u·v = u₁v₁ + u₂v₂   (result is a scalar)
Angle between vectors: cos θ = (u·v) / (|u||v|)
Direction angle: θ = arctan(y/x), adjusted for quadrant
Orthogonal: u·v = 0
Parallel: v₁/u₁ = v₂/u₂   (ratios of corresponding components are equal)

Limits

Strategies (try in this order)

1. Direct substitution — always try first
2. Factor & cancel — for 0/0 with rational expressions
3. Rationalize the numerator — for 0/0 with square roots (multiply by conjugate)

Limits at infinity

Same degree → ratio of leading coefficients
Numerator degree < denominator → limit = 0
Numerator degree > denominator → limit = ±∞ (DNE)

Fundamental trig limits

lim(x→0) sin(x)/x = 1
lim(x→0) (1 − cos x)/x = 0

One-sided limits

Two-sided limit exists only if left and right limits are equal and finite
